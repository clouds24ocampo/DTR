# Features

The HRMS Frontend provides a comprehensive suite of tools for both employees and management.

## Core Modules

### 1. Workforce Management
- **DTR Tracking**: Real-time Daily Time Record with geo-fencing and trip approval capabilities.
- **Leave Management**: Submit, track, and approve leave requests with automated balance tracking.
- **Schedule Management**: View and manage shift schedules and workplace assignments.

### 2. Human Resources (HR)
- **Applicant Tracking**: Manage the end-to-end recruitment process from job posting to hiring.
- **Employee Management**: Centralized database for employee records, documents, and performance.
- **Payroll Management**: Automated payroll calculations, payslip generation, and analytics.

### 3. Collaboration & Communication
- **Real-time Messaging**: Internal chat system with file sharing and attachment support.
- **Notifications**: Instant alerts for important updates, approvals, and system messages.
- **Document Management**: Create, edit, and share internal documents using a rich text editor.

### 4. Dashboards & Analytics
- **Role-Specific Dashboards**: Custom views for HR, Workforce, Employees, Interns, and Team Leaders.
- **Performance Management**: Tools for tracking and reviewing employee performance milestones.
- **Reporting**: Exportable reports for DTR, Payroll, and workforce metrics.

### 5. Advanced Utilities
- **Geo-fencing**: Location-based attendance verification for remote or field work.
- **PWA Support**: Install the dashboard as an app on your device for quick access.
- **Virtual Office**: (If applicable) Integration for remote collaboration environments.
