# Security Guide for Staff

Maintaining security is a collective responsibility. This guide outlines best practices for using the HRMS Dashboard securely.

## Password & Account Safety
- **Strong Passwords**: Use a unique, complex password for your HRMS account.
- **Regular Changes**: Update your password periodically using the "Change Password" modal in your profile.
- **No Sharing**: Never share your login credentials with colleagues.

## Sensitive Data Handling
- **Screen Privacy**: Be mindful of your surroundings when viewing sensitive employee or payroll data.
- **Log Out**: Always log out of the dashboard when leaving your workstation unattended.
- **Download Security**: Securely store any exported reports (PDF, CSV) and delete them when no longer needed.

## DTR & Location
- **Accurate Clocking**: Only clock in/out from authorized locations.
- **Device Security**: Ensure your device's location services are working correctly for geo-fenced attendance.

## Communication
- **Official Channels**: Use the internal messaging system for professional communication.
- **Attachments**: Be cautious when opening attachments from unknown sources within the messaging system.

## Reporting Vulnerabilities
If you discover a technical issue or security flaw, please report it immediately to the IT department or through the official feedback channel.
